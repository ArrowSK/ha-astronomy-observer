# Astronomy Observer for Home Assistant

Astronomy Observer is a Home Assistant app for evaluating observing conditions and finding worthwhile targets for the current location of a Home Assistant person.

The project is aimed primarily at experienced amateur astronomers. Its calculations are deterministic and inspectable; the app does not use a language model to decide whether an object is observable.

Development is in progress. See the app documentation in this repository for installation, configuration, scoring methodology, data provenance and limitations.
