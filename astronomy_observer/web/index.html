When should I use the optional CSV?

Only when you have a better local or higher-resolution grid than the built-in approximately 3-arcminute atlas. The optional CSV contains latitude,longitude,artificial_mcd_m2 and overrides the built-in atlas when it has a usable nearby point. A measured SQM value or Home Assistant SQM sensor is also supported.

The first calculation normally takes a little longer while current source data are collected.
