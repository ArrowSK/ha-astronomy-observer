Data reference and optional overrides

Built-in reference: Falchi et al. (2016), The New World Atlas of Artificial Night Sky Brightness, GFZ Data Services, DOI 10.5880/GFZ.1.4.2016.001. The runtime uses an approximately 3-arcminute derivative of the 2015 atlas. A measured SQM value, Home Assistant SQM sensor or higher-resolution local CSV can override it.
